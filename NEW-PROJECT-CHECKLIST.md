# New project checklist

- [ ] I can explain the objective in one or two sentences.
- [ ] I have permission to publish all data, screenshots, and outputs.
- [ ] I removed personal, confidential, and sensitive information.
- [ ] I identified whether the project is practice, personal, or authorized work.
- [ ] I listed only tools I actually used.
- [ ] I documented the steps I personally completed.
- [ ] I described quality checks and limitations.
- [ ] Any metrics are calculated and supported by evidence.
- [ ] The README explains how someone can review the project.
- [ ] I checked every file before committing it publicly.
